# 모바일 우선 연복리 계산기 & A/B 시각화 대시보드

초기 투자금과 정기 적립금, 복리 주기, 한국형 세금 체계를 반영하여 장기 투자 자산의 성장 추이를 시뮬레이션하고, 두 가지 투자 시나리오(A/B)를 한 차트에서 비교 분석할 수 있는 모바일 우선 반응형 웹 애플리케이션입니다.

---

## 🌟 주요 핵심 기능

### 1. 정밀 복리 계산 엔진
- **다양한 납입 방식**: 초기 투자원금 거치식 및 정기 적립식(매월 / 매년) 동시 지원.
- **복리 주기 선택**: 월복리(일반적 권장), 연복리, 분기복리, 일복리 지원.
- **한국형 금융 과세 반영**:
  - 일반과세 (15.4%: 소득세 14% + 지방소득세 1.4%)
  - 비과세 (0%)
  - 세금우대 / ISA (9.9%: 소득세 9% + 지방소득세 0.9%)
  - 직접 입력 (%)
- **원금 손실(마이너스 수익률) 시뮬레이션**: `-30% ~ +50%` 범위 지원 및 손실 발생 시 소득세 0원 자동 면제.

### 2. 시나리오 A / B 듀얼 비교 모드
- 한 화면에서 두 가지 전략(예: 연 7% 지수 ETF vs 연 10% 적극투자)을 동시 시뮬레이션.
- 두 시나리오의 성장 곡선을 한 차트에 오버레이 비교.
- 최종 자산 격차, 세후 순이자 차이, 수익률 격차(%p)를 한눈에 볼 수 있는 심층 비교 분석 카드 제공.
- "시나리오 A 조건 복사" 원클릭 버튼 지원.

### 3. 인터랙티브 Recharts 시각화 대시보드
- **듀얼 차트 뷰**: 누적 영역형(Stacked Area) 차트와 선형(Line) 차트 전환 지원.
- **모바일 터치 최적화 툴팁**: 손가락 터치 드래그 시 해당 연차의 원금, 이자, 총평가액을 선명한 카드 형태로 표시.
- **가독성 높은 Y축**: 금액을 `1억`, `5,000만` 단위로 직관적 축약 표기.

### 4. 모바일 퍼스트(Mobile-First) 터치 편의 UX
- **원터치 빠른 금액 증감 버튼**: `+10만`, `+50만`, `+100만`, `+1,000만`, `정정`.
- **한글 금액 실시간 환산**: `150,000,000원` 입력 시 `1억 5,000만 원` 텍스트 실시간 보조 표기 (음수 지원).
- **원클릭 프리셋 칩**:
  - 대표 수익률: `하락장 -10%`, `약세장 -3%`, `예적금 3.5%`, `지수 ETF 8%`, `공격투자 12%`.
  - 빠른 기간: `5년`, `10년`, `15년`, `20년`, `30년`.
- 슬라이더와 입력 필드 간의 60fps 무지연 양방향 실시간 동기화.

### 5. 연도별 상세 데이터 테이블 & 내보내기
- 연차별 납입원금, 당해연도 이자, 누적 순이자, 총평가액, 수익률 표 제공.
- 모바일 가로 스크롤 및 접이식 아코디언 지원.
- **엑셀 호환 CSV 다운로드**: UTF-8 BOM이 적용되어 한글 깨짐 없이 바로 열리는 CSV 파일 다운로드 제공.

### 6. 브라우저 로컬 저장
- 새로고침이나 브라우저를 닫아도 마지막 입력 시나리오를 `LocalStorage`에 자동 보관.
- 상단 헤더의 '기본값 초기화' 버튼으로 언제든 초기 상태로 복원 가능.

## 🚀 시작하기

### 필수 요구사항
- Node.js 18.0.0 이상
- npm 9.0.0 이상

### 설치 및 로컬 실행
```powershell
# 1. 패키지 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev

# 브라우저에서 http://localhost:5173 접속
```

### 프로덕션 빌드
```powershell
# TypeScript 검사 및 번들 최적화 빌드 (dist/ 생성)
npm run build
```

## 🌐 무료 웹 배포 가이드

본 프로젝트는 백엔드 없는 순수 정적 SPA이므로 무료 호스팅 서비스를 통해 1분 만에 전 세계에 배포할 수 있습니다.

```powershell
npx vercel
```

### 방법 2: Netlify Drop (드래그 앤 드롭)
1. `npm run build` 실행
2. [Netlify Drop](https://app.netlify.com/drop) 페이지에 `dist` 폴더를 마우스로 끌어다 놓기만 하면 즉시 배포 완료
