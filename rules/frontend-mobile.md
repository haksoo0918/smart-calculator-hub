# Frontend and Mobile Rules

Read this file before beginning frontend work.

## Screen-First Implementation

- For projects with a frontend, implement and validate the screen and UX flow before backend integration.
- Complete the user flow, layout, state transitions, input handling, and UX scenarios before connecting APIs or backend logic.
- Batch jobs, ETL tasks, internal schedulers, CLI-only tools, and pure backend services may follow an API- or logic-first approach.

## Mobile First

- Design for mobile screens first, then expand to tablet and desktop.
- Keep information hierarchy, spacing, tap targets, and primary actions clear on small screens.
- Optimize the initial layout for narrow viewports and avoid horizontal scrolling.
- Treat desktop as a progressive enhancement of the mobile baseline.
- Keep critical actions thumb-accessible and provide sufficient contrast.
- Validate mobile UX for forms, navigation, and dense screens before desktop expansion.
